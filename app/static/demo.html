How to demo

  1. Register two users (e.g. Asha and Ravi). Note their User IDs.
  2. Log in as the admin (created with python -m scripts.create_admin) and fund Asha's wallet.
  3. Log in as Asha and send money to Ravi. Try the failure scenarios too.
  4. Log in as Ravi to see the incoming transfer, then as admin run reconciliation.
